<h1 align="center">RolePebble</h1>

<p align="center">
  Every application, tailored: one profile, a resume and cover letter written for each job, and every application tracked from draft to offer.
</p>

<p align="center">
  <a href="LICENSE"><img alt="License: AGPL-3.0" src="https://img.shields.io/badge/license-AGPL--3.0-blue"></a>
</p>

> **Status:** early. RolePebble isn't open to the public yet. Its first hosted version is being built in this repository.

RolePebble keeps your career history in one profile. For every job you apply to, it reads the posting, shows how you match, and drafts a resume and cover letter that only use facts from your profile: what the posting asks for and your profile doesn't have is shown as a gap, never made up. You refine them in a chat, download them as PDFs, and track each application on a board from draft to offer.

## Built on Dossier

RolePebble is built on [Dossier](https://dossier.aien.me) by AienTech, a self-hosted job search app, and is a modified version of it under the same [GNU AGPL v3](LICENSE) license. [NOTICE](NOTICE) lists what's changed.

RolePebble is run by Ahmad Usama, not by the Dossier project. If you'd rather run your own copy on your own server, use Dossier itself: [dossier.aien.me](https://dossier.aien.me).
